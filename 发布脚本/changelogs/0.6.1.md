### 0.6.1

**English**

- Text boxes are now exactly as wide as buttons in the same row.
- The port's own settings work: tooltip visibility, row height, scroll wheel speed, title suffix and the list of hidden config files.
- Nowhere in the screen shows a raw translation key any more; missing translations fall back to a readable label.
- The port's own tooltips are translated.
- The theme option was removed because it never had any effect.

**中文**

- 输入框的可见宽度与同一行的按钮完全一致。
- 本模组自身配置全部生效：提示框开关、行高、滚轮速度、标题后缀、隐藏的配置文件列表。
- 界面不再出现裸的翻译键，缺翻译时回退为可读的名字。
- 本模组自身配置项的提示框已翻译。
- 移除从未生效的配色主题选项。
